## 1. Цель и научная гипотеза

### 🔬 Исследовательская гипотеза
Представление одномерного временного ряда в виде двумерного изображения с последующим применением методов **Image Inpainting** позволяет эффективнее восстанавливать сложные пространственно-временные и кросс-периодические паттерны, обеспечивая более высокую точность заполнения пропусков по сравнению с традиционными методами одномерной интерполяции и классического машинного обучения.

### ❓ Ключевой исследовательский вопрос
**Каким образом оптимально преобразовывать временной ряд в двумерное изображение, и как геометрия/семантика этого преобразования влияет на качество реконструкции пропусков различного типа (точечных, протяжённых, смешанных)?**

### 💡 Теоретический базис и новизна
Работа опирается на идеи статьи:
> *Fu et al.* «Filling time-series gaps using image techniques: Multidimensional context autoencoder approach for building energy data imputation» (*Applied Thermal Engineering*, 2024).

В оригинальной статье энергопотребление сворачивалось в двумерную матрицу «час недели × номер недели» ($168 \times 52$), а пропуски восстанавливались автоэнкодером с частичными свёртками (**Partial Convolution, PConv**).

**Новизна данной курсовой работы:**
1. **Систематическое сравнение способов кодирования временного ряда в изображение**:
   - Нарезка по периодам/сезонностям (*Slice representation* с различными шагами и ориентациями);
   - Частотно-временное преобразование (комплексная спектрограмма *STFT* с каналами $\text{Re}$ и $\text{Im}$);
   - Вейвлет-преобразование (скалограмма непрерывного вейвлет-преобразования *CWT*).
2. **Кросс-модельный бенчмарк**: одновременное сопоставление трёх классов методов:
   - Классические модели и ML прямо по временному ряду (Linear, KNN, LightGBM с лагами);
   - Классические алгоритмы компьютерного зрения (Telea, Navier-Stokes, маскированная медиана, Weekly Persistence);
   - Глубокие нейросетевые модели (U-Net, PConv, Masked Autoencoders).

## 2. Общая схема экспериментального пайплайна

Сравнение проводится строго на **одинаковых масках пропусков** (с фиксированным `seed`), а расчёт метрик качества выполняется **исключительно на искусственно удалённых точках**.

```mermaid
flowchart TD
    A[1. Генерация / Загрузка временного ряда] --> B[2. Внесение искусственных пропусков\n(point / continuous / mixed)\n+ сохранение бинарной маски]
    
    B --> C1[Ветка A: Прямые методы]
    B --> C2[Ветка B: Методы через Image Inpainting]

    subgraph Branch_A [Ветка A: Одномерные методы]
        C1 --> D1[ClassicalImputer\n- Linear extrapolation\n- KNN Regressor\n- LightGBM с лагами и сезонностью]
        D1 --> E1[Восстановленный ряд A]
    end

    subgraph Branch_B [Ветка B: 2D Image Inpainting]
        C2 --> D2[TimeSeries2Image\n- Первичное заполнение\n- Построение матрицы/спектра данных\n- Построение матрицы/спектра маски]
        D2 --> D3[Модели Image Inpainting\n- Telea / Navier-Stokes\n- Weekly Persistence\n- U-Net / PConv / MAE]
        D3 --> D4[Обратное преобразование\n(from_slice / from_spectrogram / from_wavelet)\n+ наложение исходной маски (use_mask=True)]
        D4 --> E2[Восстановленный ряд B]
    end

    E1 --> F[4. Расчёт метрик: RMSE, MAE, R²\n(строго на пропущенных точках: mask == 0)]
    E2 --> F
    F --> G[5. Итоговое сравнение моделей и способов преобразования]
```

## 3. Архитектура и реализованный функционал

Реализация выполнена на Python с поддержкой исполнения в Jupyter Notebook, Google Colab и Kaggle (автоматическое переключение CPU / GPU).

### 3.1. Генератор синтетических данных

Функция `generate_time_series(...)` формирует гибкие синтетические ряды по аддитивной схеме:
$$\text{Series}(t) = \text{Trend}(t) + \sum_{k} \text{Seasonality}_k(t) + \text{Noise}(t)$$

- **Тренды**:
  - Линейный: $y(t) = \text{slope} \cdot t$;
  - Степенной: $y(t) = a \cdot t^p$;
  - Логарифмический: $y(t) = a \cdot \ln(t + 1)$.
- **Сезонность**: сумма произвольного числа гармоник:
  $$\sum_{k=1}^K A_k \sin\left(\frac{2\pi t}{T_k} + \phi_k\right)$$
- **Шумовые компоненты**: гауссов шум $\mathcal{N}(\mu, \sigma^2)$ и распределение Лапласа $\text{Laplace}(\mu, b)$.
- **Визуализация**: `plot_time_series` и `plot_multiple_time_series` для сопоставительного анализа.

---

### 3.2. Генератор и визуализатор пропусков

Функция `create_missing_values(series, missing_type, ...)` возвращает кортеж `(series_with_nan, mask)`, где:
- $\text{mask} = 1$ — валидные (известные) данные;
- $\text{mask} = 0$ — искусственный пропуск ($\text{NaN}$).

Режимы генерации пропусков:
1. **`point` (точечные)**: случайное удаление заданного процента точек (MCAR).
2. **`continuous` (непрерывные блоки)**:
   - Автоматический подрежим: генерация непересекающихся блоков со случайной длиной до `max_length` до достижения суммарного процента пропусков;
   - Ручной подрежим: задание явного списка индексных диапазонов (например, `[[10, 11, 12], [25, 26, 27, 28]]`).
3. **`mixed` (смешанные)**: комбинация точечных выбросов и блочных выпадений данных.
4. **Визуализация**: `plot_series_with_missing` с подсветкой областей с $\text{NaN}$ полупрозрачным красным фоном и статистикой доли пропусков.

---

### 3.3. Модуль преобразования `TimeSeries2Image`

Центральный модуль пайплайна, обеспечивающий прямое и обратное отображение между $\mathbb{R}^N$ и $\mathbb{R}^{C \times H \times W}$.

#### Внутренний механизм:
1. Формирование маски пропусков $\text{mask\_series} \in \{0, 1\}^N$.
2. Первичное базовое заполнение (`fill_missing`): `linear` (по умолчанию), `mean`, `median`, `zero`, `constant`.
3. Совместное синхронное преобразование данных и маски в тензоры изображения.

#### Методы трансформации:
| Метод | Описание | Основные параметры | Выходной формат |
|---|---|---|---|
| **`to_slice`** | Разбиение ряда на периодические сегменты и укладка в 2D матрицу (период $\times$ номер периода). | `seasonality`, `periods`, `step`, `rows_are_time` | Данные: $(H, W)$, Маска: $(H, W)$ |
| **`to_spectrogram`** | Оконное преобразование Фурье (STFT) с сохранением комплексных компонент. | `n_fft`, `hop_length`, `window`, `center`, `mask_mode`, `mask_threshold` | Данные: $(2, F, T)$ ($\text{Re}, \text{Im}$), Маска: $(F, T)$ |
| **`to_wavelet`** | Непрерывное вейвлет-преобразование (CWT) через PyWavelets (скалограмма). | `wavelet`, `scales_range`, `num_scales`, `mask_mode`, `mask_threshold` | Данные: $(S, N)$, Маска: $(S, N)$ |

#### Особенности построения масок и обратного хода:
- **Размытие маски в STFT / CWT**: маска на спектрограмме/вейвлете формируется с учётом окна влияния:
  - `strict`: пиксель спектра маскируется ($0$), если в окно попал хотя бы один исходный $\text{NaN}$;
  - `threshold`: пиксель маскируется, если доля валидных отсчётов в окне ниже `mask_threshold`.
- **Обратное преобразование**:
  - `from_slice`: распаковка матрицы в одномерный вектор;
  - `from_spectrogram`: iSTFT над восстановленным спектром $\text{Re} + j \cdot \text{Im}$ с фильтрацией артефактов и клиппингом выбросов;
  - `from_wavelet`: `pywt.icwt` по матрице коэффициентов.
- **Сохранение исходных точек (`use_mask=True`)**:
  $$y_{\text{final}}[i] = \begin{cases} y_{\text{orig}}[i], & \text{если } \text{mask}[i] = 1 \\ y_{\text{predicted}}[i], & \text{если } \text{mask}[i] = 0 \end{cases}$$
- **Вспомогательные операции**: `to_all` / `from_all`, сериализация `save` / `load` (`.npz` + `.json`), диагностика `visualize`, `compare_reconstruction`, `get_data`, `reset`.

### 3.4. Бейзлайн: класс `ClassicalImputer`

Реализует одномерные алгоритмы восстановления пропусков для прямого бенчмаркинга:

- **`linear`**: линейная интерполяция с возможностью выбора граничной экстраполяции (`extrapolate`, `ffill`, `bfill`).
- **`knn`**: регрессия K-ближайших соседей (`KNeighborsRegressor`).
- **`lgbm`**: градиентный бустинг деревьев решений (`LGBMRegressor`).

#### Признаковое пространство (Feature Engineering):
- **Лаговые переменные**: авторегрессионные лаги $t-1, \dots, t-k$.
- **Сезонные лаги**: настраиваемый словарь вида `{24: 2, 168: 1}` (лаги на 1 и 2 суток, 1 неделю назад).
- **Временные циклы**: синусно-косинусное кодирование циклических гармоник:
  $$\sin\left(\frac{2\pi t}{T}\right), \quad \cos\left(\frac{2\pi t}{T}\right)$$

#### Обучение и предсказание:
- Обучение происходит исключительно на точках с $\text{mask} = 1$, у которых все лаговые признаки валидны.
- Реализован **итеративный алгоритм предсказания** (`n_iterations`): на каждом проходе модель предсказывает пропуски, которые на следующем шаге включаются в признаковое пространство для заполнения более глубоких горизонтов.
- Робастная обработка $\text{NaN}$ в признаках для KNN (импутация средними по `train`).

### 4.1. Не-нейросетевые методы inpainting
1. **Алгоритмы Telea и Navier-Stokes** (`cv2.inpaint`): методы цифровой обработки изображений, распространяющие информацию с контуров пропусков внутрь маски вдоль изофот.
2. **Weekly Persistence в пространстве 2D**: для пропущенной ячейки $(h, w)$ берётся значение из аналогичной временной фазы предшествующего периода $(h, w-1)$.
3. **Маскированная медианная и билинейная фильтрация**: локальная фильтрация с расчётом статистик только по валидным пикселям окрестности.

### 4.2. Нейросетевые архитектуры
1. **U-Net**: полносвёрточный автоэнкодер со skip-connections. Вход: тензор данных с пропусками + бинарный канал маски $\to$ выход: восстановленное 2D изображение.
2. **Partial Convolution (PConv) U-Net**: свёрточные слои с автоматической перенормировкой по маске валидных пикселей и динамическим сужением маски по слоям (архитектура из статьи Fu et al.).
3. **Masked Autoencoder (MAE)** *(опционально)*: архитектура на базе Vision Transformer (`timm`), восстанавливающая патчи изображения.
4. **Маскированные функции потерь**: оптимизация $\mathcal{L}_{\text{MSE}}$ преимущественно или строго на позициях искусственных пропусков ($\text{mask} = 0$).

### 4.3. Сравнительное исследование способов трансформации

Для фиксированной базовой модели (например, U-Net) проводится оценка качества восстановления при различных способах представления ряда:

| № | Конфигурация | Параметры | Фокус проверки |
|---|---|---|---|
| 1 | **Slice (Суточный)** | `seasonality=24`, строки — часы, столбцы — дни | Суточная периодичность |
| 2 | **Slice (Недельный)** | `seasonality=168`, строки — часы недели, столбцы — недели | Кросс-недельные паттерны |
| 3 | **Slice (Транспонированный)** | Строки и столбцы инвертированы | Влияние ориентации свёрточных ядер |
| 4 | **Slice с перекрытием** | `step < seasonality` (скользящее окно) | Аугментация объёма выборки |
| 5 | **Спектрограмма (STFT)** | Сетка по `n_fft` и `hop_length` | Гладкость гармонических составляющих |
| 6 | **Вейвлет (CWT)** | Вейвлет Морле, варьирование масштабов `scales_range` | Локализация нестационарных всплесков |

## 5. Ключевые тонкие места и ограничения

1. **Обратимость частотных представлений (STFT/CWT)**:
   Обратное преобразование Фурье и тем более обратный вейвлет `icwt` являются численно приближёнными при маскировании коэффициентов и могут привносить краевые артефакты.
2. **Размытие маски (Smearing Effect)**:
   При оконных преобразованиях один пропущенный отсчёт во временной области затрагивает целое окно во времени, что требует калибровки порогов `strict` vs `threshold`.
3. **Влияние первичной интерполяции**:
   Для расчёта непрерывного спектра пропуски предварительно сглаживаются (например, линейно), что вносит систематическое смещение, учитываемое при анализе результатов.
4. **Объём данных и аугментация**:
   При редкой сезонности (например, неделя = 168 часов) годовой ряд даёт лишь 52 среза. Необходимы техники аугментации: скользящее окно с малым шагом (`step`), случайные временные сдвиги (time shifting), горизонтальные инверсии.
5. **Искажение пропорций при масштабировании**:
   Приведение матриц к квадрату $N \times N$ билинейной интерполяцией нарушает физическую сетку временного ряда. Ресайз должен выполняться только на этапе батчинга нейросети, но не при хранении.

### Пример использования (базовый пайплайн)
```python
import numpy as np
from src.synthetic import generate_time_series
from src.missing import create_missing_values
from src.ts2image import TimeSeries2Image
from src.classical import ClassicalImputer

# 1. Генерация временного ряда
series = generate_time_series(
    length=2000,
    trend_type="linear",
    trend_params={"slope": 0.05},
    seasonal_periods=[24, 168],
    seasonal_amplitudes=[10.0, 5.0],
    noise_type="gaussian",
    noise_params={"std": 1.0},
    seed=42
)

# 2. Внесение пропусков (блочные пропуски)
series_with_nan, mask = create_missing_values(
    series, 
    missing_type="continuous", 
    missing_ratio=0.15, 
    max_length=24, 
    seed=42
)

# 3. Преобразование в 2D матрицу (Slice)
ts2img = TimeSeries2Image(fill_missing="linear")
img_data, img_mask = ts2img.to_slice(series_with_nan, seasonality=24)

# 4. Обратное восстановление
reconstructed = ts2img.from_slice(img_data, use_mask=True)

# 5. Классический бейзлайн (LightGBM с сезонными лагами)
imputer = ClassicalImputer(
    model_type="lgbm",
    lags=3,
    seasonal_lags={24: 2, 168: 1}
)
imputed_series = imputer.fit_predict(series_with_nan, mask)
```
